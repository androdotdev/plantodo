## Pre-major-update fixes (research audit — 2026-07-31)

> Findings from a 4-agent read-only audit (bugs / security / refactor / launch gaps). Lines verified by reading source; fix directions included, no code changed.

### Must fix — confirmed bugs
- [ ] **Dashboard "Save Data" nests post data under a `data` key** — `web/app/post/edit/[id]/page.tsx:95` sends `{data: parsed}`, but PATCH `/api/posts/:id/data` merges the body directly (CLI + MCP send the raw object). `{{placeholder}}` rendering breaks for dashboard saves. Fix: send `JSON.stringify(parsed)`.
- [ ] **Private posts served with `Cache-Control: public, max-age=300`** — `web/app/p/[id]/route.ts:162-169`; denial paths use `private, no-store` (lines 103-115). Private HTML + `window.__PH_DATA` + `?key=` token cacheable by shared caches. Fix: `private, no-store` when `post.isPrivate`.
- [ ] **Public GET /api/posts/:id leaks owner `userId`** — `db.select()` returns the full row (`web/app/api/posts/[id]/route.ts:16-24`); same for `/data`. Fix: project only intended fields.
- [ ] **PATCH /api/posts/:id accepts mixed-type garbage** — AND-chain guard (`[id]/route.ts:59`); `{html: 123, isPrivate: true}` persists non-strings. Fix: per-field type validation.
- [ ] **CLI `setup` ignores `POST_API_KEY`** — documented non-interactive flow (`cli/README`) prompts instead of using the env var. Related to the known `post_` prefix bug.
- [ ] **`/p/:id/` trailing slash breaks private access** — `web/proxy.ts:48` signs the token for `id/` (`path.replace("/p/","")`), route compares against normalized `id` → owner gets 403. Fix: strip trailing slash before signing.
- [ ] **Proxy appends a second `key` param when a stale token is in the URL** — `web/proxy.ts:52-55`; viewer reads the first (stale) token → 403 for the owner. Fix: replace existing `key`.
- [ ] **`withError` returns 500 with raw `err.message`** — malformed JSON body → 500 + parser text; DB errors echoed (`web/lib/with-error.ts:7-15`). Fix: 400 on JSON parse errors, generic 500, log server-side.

### Must fix — credential lifecycle / security
- [ ] **MCP "Generate New URL" leaves the previous token active** — no server-side uniqueness (`web/app/api/keys/route.ts:27-48`); dashboard `generateMcpKey` doesn't revoke (`McpSection.tsx:37-66`). AGENTS.md "replace in place" claim false. Fix: revoke existing `mcp_` key on generate.
- [ ] **Private-post capability tokens can't be revoked** — 30-day HMAC, no version (`web/lib/post-token.ts:4-28`); private→public→private keeps old tokens valid. Fix: token-version column on `posts`, rotate on visibility toggle.
- [ ] **Dashboard-created API keys: no rate limit, no expiry by default** — `POST /api/keys` sets `rateLimitEnabled: false` unless checked; `expiresIn` never sent; plugin default null (`web/lib/auth.ts:22-29`). Decide policy before launch.
